Zen test quality review

Jev’s static assessment, with source and expected results. Scores are review heuristics—not proof that a test is valid or invalid. Highest review priority comes first. Confidence describes the model’s recommendation; mutation coverage has not been measured. Nothing is deleted. Before/after uses the same model and questions; score changes on unedited tests reflect review variability.
How the ranking works

Quality = clarity 15% + oracle strength 35% + likely bug sensitivity 30% + boundary coverage 10% + determinism 10%. Each Jev score is scaled from 0–4 to 0–100. Review priority = 100 − quality, plus 20 for missing context and 10 for recommendation confidence below 60%. This is a triage rule, not a measured correctness percentage.
